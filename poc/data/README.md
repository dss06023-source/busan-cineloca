## 좌표 실패 원인 (2026-11-09)

주소가 있는데 좌표를 못 찾은 315곳을 같은 주소로 다시 조회해 나눴습니다.

| 원인 | 곳 | 고치는 방법 |

| 배치 중 검색 API 오류 응답(ResponseFormatError 144건). 다시 부르면 찾음 | 153 | 오류 코드를 기록하고, 일시 오류면 잠시 뒤 다시 부르기 |
| 건물번호 뒤에 상호·층·설명이 붙어 검색이 안 됨(예: '… 센텀5로 55 1층 ○○') | 약 83 | 검색어를 '도로명 + 건물번호'(또는 '동·리 + 지번')까지만 자르기 |
| 그래도 못 찾음(고가교 하부 등 건물 아닌 곳) | 약 73 | 관리자 수동 보정(manual) |
| 부산 밖(김해·양산) | 6 | 범위 밖으로 두거나 수동 보정 |

위 두 가지를 고치면 주소 있는 곳 기준 약 92.5%(978/1,057)로 목표를 넘을 것으로 계산됩니다(재조회 결과로 낸 추정이며 배치로는 아직 확인하지 않음).
주소가 없는 321곳은 장소명만 있어 주소 API로는 채울 수 없고, 같은 장소의 씨네맵 주소나 관리자 보정이 필요합니다.

이 작업 환경(클라우드)에서는 business.juso.go.kr의 https(443) 연결이 끊겨 http로 바꿔 실행했습니다. 저장소 설정(`config/adapters.yaml`)은 https 그대로입니다.
